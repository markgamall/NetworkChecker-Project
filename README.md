# NetworkChecker - Limitless Care Network Provider Locator
A modern Angular application that helps healthcare staff validate their credentials and locate network providers within the Limitless Care network.

## Features
- Staff ID Validation: Validate healthcare staff credentials using insurance numbers
- Provider Search: Browse and search through network healthcare providers
- Branch Locations: View detailed information about provider branches and locations
- Interactive Maps: Integrated Google Maps for location visualization
- Provider Details: Access comprehensive provider information including specialties, contact details, and location data
- Responsive Design: Mobile-friendly interface with modern UI components

## Tech Stack
Framework: Angular
